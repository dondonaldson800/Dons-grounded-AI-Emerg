## ⚡ 1. The Master One-Command Automation (`./automate.sh`)

Whenever you make any change, simply run:
```bash
./automate.sh
```
Or with a custom message:
```bash
./automate.sh "Added new search features"
```

### What `./automate.sh` Does Automatically:
1. **Compiles & Verifies** the web app bundle (`npm run build`).
2. **Validates Store SKUs** across Google Play, Apple, Amazon, and Samsung.
3. **Stages & Commits** all source files and assets.
4. **Pushes directly to GitHub** (`dondonaldson800/Dons-grounded-AI-Emerg`).
5. **Triggers GitHub Actions Workflows** to build Android APK and AAB binaries automatically in the cloud!

## ☁️ 2. Active Cloud Workflows (GitHub Actions)

Your repository (`.github/workflows/`) now contains 3 automated cloud pipelines:

### 📱 Workflow A: `android-build.yml` (Master Android Pipeline)
* **Triggers:** Every push to `main` branch, or manual one-click trigger.
* **What it builds in the cloud:**
  * **Universal Android APK:** For Amazon Appstore, sideloading, Chromebooks, and Fire tablets.
  * **Android App Bundle (.aab):** For Google Play Console & Samsung Galaxy Store.
* **Where to get files:**
  * Go to: `https://github.com/dondonaldson800/Dons-grounded-AI-Emerg/actions`
  * Click on the latest workflow run.
  * Scroll down to **Artifacts** to download `dons-grounded-ai-debug-apk` and `dons-grounded-ai-bundle-aab`.

### 🛡️ Workflow B: `ci.yml` (Continuous Integration)
* **Triggers:** Every push & pull request.
* **What it verifies:**
  * Compiles Vite/React app to prevent syntax errors.
  * Checks that the store SKU registry (`export_all_store_skus.json`) is intact.

### 🏷️ Workflow C: `release.yml` (Automated Store Release Publishing)
* **Triggers:** When you tag a release (e.g., `v1.0.0`) or click "Run workflow" in GitHub Actions.
* **What it does:** Builds production APK + AAB and publishes a official GitHub Release with direct download links.
